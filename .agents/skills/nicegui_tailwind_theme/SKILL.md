# NiceGUI Tailwind Theme from HTML

When converting an HTML file (often generated by a design tool or an LLM) that uses extensive Tailwind CSS utility classes into a NiceGUI application, the resulting Python code can become very cluttered and hard to read. To solve this, always use the **Theme Class Pattern**.

## The Problem
A direct 1-to-1 translation of an HTML file to NiceGUI looks like this:

```python
ui.label('Dashboard').classes('text-2xl font-extrabold tracking-tight mb-4 text-[#0d1c12]')
```
This reduces Python readability and violates the DRY (Don't Repeat Yourself) principle if multiple elements share the same styling.

## The Solution: Theme Class Pattern
Extract all Tailwind CSS classes into a dedicated Python class (usually in a separate `theme.py` file or at the top of the script). This class acts as a central design system.

### 1. Create the Theme Class
Group related styles together as class attributes:

```python
class Theme:
    # Setup method for Tailwind Config and Fonts
    @staticmethod
    def setup():
        ui.add_head_html('''
        <script src="https://cdn.tailwindcss.com?plugins=forms,container-queries"></script>
        <!-- Add your fonts and custom CSS here -->
        ''')
        ui.query('body').classes('bg-white text-gray-900 m-0 p-0 base-font')

    # Layout
    LAYOUT_ROOT = 'min-h-screen flex w-full'
    LAYOUT_MAIN = 'flex-1 p-8 overflow-y-auto'
    
    # Typography
    H1 = 'text-2xl font-extrabold tracking-tight'
    TEXT_MUTED = 'text-gray-500 text-sm'
    
    # Components
    CARD = 'bg-white border rounded-xl p-6 shadow-sm hover:shadow-md transition-all'
    BTN_PRIMARY = 'bg-green-500 text-white px-6 py-2 rounded-lg font-bold hover:bg-green-600'
```

### 2. Use the Theme Class in the UI
Import the theme and apply the constants to the UI elements. This makes the code semantic and incredibly clean:

```python
from nicegui import ui
# Assuming Theme is defined in theme.py:
# from theme import Theme as T

def build_ui():
    Theme.setup()
    
    with ui.element('div').classes(Theme.LAYOUT_ROOT):
        with ui.element('main').classes(Theme.LAYOUT_MAIN):
            ui.label('My Dashboard').classes(Theme.H1)
            
            with ui.element('div').classes(Theme.CARD):
                ui.label('This is a card').classes(Theme.TEXT_MUTED)
                ui.button('Click Me').classes(Theme.BTN_PRIMARY)
```

## Benefits of this Approach
1. **Clean Code**: Python UI code focuses on structure and logic, not styling.
2. **Reusability**: You can import `Theme` across multiple pages (`devices.py`, `settings.py`) to ensure UI consistency.
3. **Easy Maintenance**: Want to change the primary button color? Change it in one place in the `Theme` class.
4. **IDE Support**: You get autocomplete for your design system (`Theme.BTN...`), preventing typos in long Tailwind class strings.

Always apply this pattern when a user asks to convert an HTML/Tailwind design into a nicegui application and prioritizes readability and reusability.
